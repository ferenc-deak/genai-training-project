Retrieval Augmented Generation, commonly called RAG, is a technique that combines information retrieval with large language models. Instead of relying only on the knowledge stored inside the language model, a RAG system first searches an external knowledge base for relevant information and then provides that information as context to the model before generating an answer.

A typical RAG pipeline starts with document ingestion. Documents such as text files, PDFs, manuals, or web pages are collected and prepared for indexing. During preprocessing, unnecessary formatting may be removed and the documents are cleaned to improve retrieval quality.

The next step is chunking. Large documents are divided into smaller chunks because embedding models work better with shorter pieces of text. Choosing an appropriate chunk size and overlap is important because chunks that are too large may contain unrelated information, while chunks that are too small may lose important context.

Each chunk is converted into a numerical vector called an embedding using an embedding model. Embeddings capture the semantic meaning of text so that similar concepts are located close together in vector space. The embeddings are stored inside a vector database such as Chroma or FAISS.

When a user asks a question, the question is also converted into an embedding. The vector database performs similarity search to retrieve the most relevant chunks. Some systems improve retrieval using hybrid search, which combines semantic similarity with keyword matching, or by applying a reranker that reorders retrieved results according to their relevance.

Finally, the retrieved chunks are included in the prompt sent to a large language model. The model is instructed to answer only using the provided context and to admit when the answer cannot be found. RAG systems reduce hallucinations, improve factual accuracy, and allow language models to answer questions about private or recently updated documents. They are commonly used in enterprise search, customer support, document assistants, and AI-powered knowledge bases.
